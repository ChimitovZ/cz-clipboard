# CZ Clipboard

Менеджер буфера обмена для Windows 10 и 11. История за выбранный срок, поиск, трей, вставка в предыдущее окно.

Данные только локально: `%APPDATA%/CZ Clipboard`.

## Запуск в разработке

Нужны Node.js 20+, Python и средства сборки native-модулей (Visual Studio Build Tools с workload «Desktop development with C++») для `better-sqlite3`.

```bat
npm install
npm run dev
```

`dev` поднимает Vite на `127.0.0.1:5173` и открывает Electron. После старта иконка появляется в трее. Окно истории: `Ctrl+Shift+V`.

## Сборка установщика

```bat
npm run dist
```

Артефакты в `release/`: NSIS-установщик и portable `.exe`.

Скрипты:

- `dev` - разработка
- `build` - только Vite (renderer)
- `dist` - Vite + electron-builder

## Горячие клавиши

| Клавиша | Действие |
| --- | --- |
| Ctrl+Shift+V | Показать / скрыть окно (хоткей меняется в настройках) |
| Esc | Закрыть окно |
| Стрелки | Навигация по списку |
| Enter | Вставить запись в предыдущее окно |
| Shift+Enter | Вставить как простой текст |
| Ctrl+1 … Ctrl+9 | Вставить одну из первых девяти записей |
| Delete | Удалить запись |
| Ctrl+P | Закрепить / открепить |
| Ctrl+клик | Мультивыбор для слияния |

Окно закрывается при потере фокуса. Закрытие окна не завершает приложение: выход только из меню трея.

## OCR

Поиск по тексту на картинках через tesseract.js. Сетевых загрузок нет. Положите `eng.traineddata` и `rus.traineddata` в папку `tessdata` проекта (или в `%APPDATA%/cz-clipboard/tessdata`) и включите OCR в настройках.

## Приватность

- Формат `ExcludeClipboardContentFromMonitorProcessing` не сохраняется
- Чёрный список процессов
- Опция не сохранять похожее на пароль или номер карты
- Пауза записи из трея и из окна
- Опциональное шифрование текстовых полей через Windows DPAPI (`safeStorage`)
